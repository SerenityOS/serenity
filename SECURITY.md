# Security Policy

SerenityOS is a hobby operating system developed by volunteers. It is unreleased software still in early development, and so bugs and vulnerabilities that affect only SerenityOS can be safely disclosed publicly.

The [Ladybird Browser project](https://github.com/LadybirdBrowser/ladybird) has inherited a number of libraries and supporting components from SerenityOS. Even after the projects have diverged, a bug or vulnerability may still be applicable to both projects.
Therefore, checking a to-be-disclosed issue against the [Ladybird security policy](https://github.com/LadybirdBrowser/ladybird/blob/master/SECURITY.md) (and disclosing it to Ladybird first if necessary) is appreciated.

If you find an issue, we would prefer if you report it as a [GitHub issue](https://github.com/SerenityOS/serenity/issues/new). If your issue was found using a fuzzer, please check [oss-fuzz](https://bugs.chromium.org/p/oss-fuzz/issues/list?q=label:Proj-serenity) first to see if it has already been recorded.
